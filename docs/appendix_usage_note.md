# Appendix D. Local use of the index

Nearest Prior Work is a local application distributed with article metadata and section vectors. After installation, scholars open a page on their own computer and choose a manuscript, paste a passage, or enter an indexed article's DOI. For manuscripts, a scholar's own language model identifies section boundaries; the application cuts the original text, maps it to the index sections, and allows the scholar to inspect and adjust the mapping before retrieval. Codex CLI and Claude Code subscriptions, model-provider API keys, and local model endpoints are supported. When a cloud provider is selected, extracted manuscript text is sent to that provider for structure identification.

Similarity retrieval runs locally and returns article metadata and scores, without article abstracts or full text. Scholars can retrieve the closest articles overall or for a selected section, filter journals and years, and export the current results. Section-specific retrieval searches the entire eligible collection. Detailed section ranks use the full indexed-section population, while result-list positions reflect the selected filters. Shared-section coverage is displayed; overall scores retain the mean over shared sections.
