Nearest Prior Work bundled index (v2)

10,357 articles from seven management journals, 1996-2026.
Contents: article metadata (DOI, title, journal, year), section vectors and reference distributions.
No article abstracts, full text, PDFs or chunk vectors are included.

The index is already included in the application repository. Do not install a separate data package.
From the repository root, use start.bat (Windows) or bash start.sh (macOS/Linux), then follow
README.md and docs/quickstart.md. First setup downloads application dependencies and search files.
After preparation, similarity retrieval runs locally without an internet connection.
Cloud CLI/API section identification sends your manuscript to the provider you select and needs a connection.
